# Quiz Generation Prompts

## Multiple Choice Quiz

```
Generate a multiple-choice quiz on [THEME] with [NUMBER] questions. For each question:

1. Create a clear, concise question.
2. Provide four answer options (A, B, C, D), with only one correct answer.
3. Mark the correct answer.
4. Include a brief explanation for the correct answer.

Make the questions varied in difficulty, engaging, and appropriate for [AUDIENCE_LEVEL].
```

## True/False Quiz

```
Generate a true/false quiz on [THEME] with [NUMBER] questions. For each statement:

1. Create a clear, factual statement that is either true or false.
2. Indicate whether the statement is true or false.
3. Provide a brief explanation why it's true or false.

Ensure the statements are not ambiguous and cover various aspects of the theme.
```

## Flashcard Quiz

```
Create a set of [NUMBER] flashcards on [THEME]. For each flashcard:

1. Front: A clear, concise question, term, or concept.
2. Back: The comprehensive answer, definition, or explanation.

Make the flashcards educational, covering key aspects of the theme with progressive difficulty.
```

## Timed Quiz

```
Generate a timed quiz on [THEME] with [NUMBER] questions of increasing difficulty. For each question:

1. Create a clear question that can be answered quickly.
2. Provide the correct answer.
3. Suggest an appropriate time limit (in seconds).

Design questions that test both recall speed and understanding of the theme.
```

## Fill-in-the-Blank Quiz

```
Create a fill-in-the-blank quiz on [THEME] with [NUMBER] questions. For each question:

1. Write a sentence or paragraph with one or more key terms removed, indicated by blanks.
2. Provide the correct word(s) for each blank.
3. Include a brief explanation of why these are the correct answers.

Ensure that the context provides enough clues for a knowledgeable person to determine the answer.
```
