# Theme Suggestion Prompts

## General Theme Suggestions

```
Suggest [NUMBER] interesting and diverse quiz themes suitable for a multiplayer quiz game. For each theme:

1. Provide a concise title (3-5 words).
2. Write a brief description (1-2 sentences).
3. List 3-5 example questions that might appear in this quiz.
4. Suggest an appropriate audience level (beginner, intermediate, advanced).

Aim for a mix of academic, pop culture, scientific, historical, and fun themes that would appeal to a wide audience.
```

## Category-Specific Theme Suggestions

```
Suggest [NUMBER] engaging quiz themes within the category of [CATEGORY]. For each theme:

1. Provide a catchy, specific title.
2. Write a brief description explaining the theme's focus.
3. Suggest 3 example questions that highlight the theme's content.
4. Indicate the knowledge level required (casual, enthusiast, expert).

Make the themes specific enough to be interesting but broad enough to generate multiple quality questions.
```

## Educational Theme Suggestions

```
Suggest [NUMBER] educational quiz themes suitable for [AGE_GROUP/GRADE_LEVEL] students. For each theme:

1. Provide an engaging, age-appropriate title.
2. Explain how the theme connects to standard educational objectives.
3. Suggest 3 example questions of varying difficulty levels.
4. Note any visual elements that might enhance learning (diagrams, maps, etc.)

Focus on themes that build knowledge while keeping students engaged and interested.
```
