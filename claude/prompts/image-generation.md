# Image Generation Prompts

## Theme Preview Images

```
Create a visually engaging preview image for a quiz about [THEME]. The image should:

1. Clearly represent key elements of the theme
2. Be colorful and attention-grabbing
3. Work well at thumbnail size (maintain visual clarity when small)
4. Include subtle visual references to the quiz content
5. Have a clean background that allows text overlay if needed

The style should be [STYLE] (e.g., cartoon, realistic, minimalist) and appropriate for [AUDIENCE].
```

## Question Illustration Images

```
Create an illustration for a quiz question about [SPECIFIC_TOPIC]. The image should:

1. Directly relate to the question content: [QUESTION]
2. Provide visual context without revealing the answer
3. Be clear and understandable
4. Use a consistent style matching the quiz theme

Avoid including text in the image unless specifically requested.
```

## Game UI Elements

```
Design a [UI_ELEMENT] (e.g., button, timer, score display) for a multiplayer quiz game. The element should:

1. Have a [STYLE] aesthetic (e.g., playful, minimalist, retro)
2. Use the following color scheme: [COLORS]
3. Be easily identifiable for its purpose
4. Work well on both desktop and mobile screens
5. Match the overall game theme of [THEME]

Ensure the design is accessible with good contrast and clear visual affordances.
```
